1. POSITIVE DIMENSION FOR THE SPORADIC FAMILY

I reconstructed the carry identities and the dimension argument for
M_k = 621*3^(4k)-20 for every k >= 0.

The carry-path lemma is valid: the complete binary output word identifies
all output prefixes modulo 3^j; the integer recurrence yields nonnegative
carries. For a fixed pair of return words, all carries range over a finite
set, so the terminal carry disappears in the 3-adic limit. A fixed entry
prefix acts by a 3-adic similarity and preserves dimension.

For k=0 the three displayed paths enter carry 69 and give return words of
lengths 3 and 12, with distinct first input digits. For k>=1 I checked:
- the entry word has length L=12k+6 and value
  (540t^2+261t-1)/20, where t=81^k;
- its output is (151281t^2-5841t+20)/20 and final carry 23;
- the given base-81 output expression uses only ternary-binary digits,
  fits within L positions, and treats k=1 separately;
- the additional input10/output01 segment reaches c=69t;
- the short return word has length m=4k+3 and value3t, satisfying
  (621t-20)*3t+69t = 9t+(27t)*69t;
- the concatenated long return word has length L, and direct geometric
  summation gives 81t^3+(63/20)t^2+(7/30)t-1/20;
- its asserted output follows by substituting this expression in
  M*b+c-3^L*c. The digit expansion fits L positions, including the k=1
  merged digit28, and every base-81 digit has ternary digits0,1.

The two return words start with different input digits. This makes them
prefix-distinguishable, which is the actual separation needed for the
variable-length construction. The disjoint subsystem has dimension d_k
specified by 3^(-m_k*d_k)+3^(-L_k*d_k)=1. The positive solution is unique
because the left side decreases continuously from2 to0. For the lower
bound, give a block of length ell weight3^(-ell*d_k). A ternary cylinder
of depth n determines the common completed-block prefix; its length is
at least n-max(m_k,L_k). This gives a uniform Frostman estimate. Stopping
at the first block crossing n gives the converse bound for this subsystem.
A fixed entry prefix preserves its dimension.

The exactness claim MUST remain restricted to the constructed subsystem.
For the full C(1,M_k), the conclusion is only dim_H C(1,M_k)>=d_k>0.
The theta corollary is valid: theta^(-1)+theta^(-4)=1 and L_k<=4m_k,
so d_k>=log_3(theta)/m_k; for k>=1 the inequality is strict.

The old nonrepresentation theorem supplies M_k outside the finite-witness
set. Thus the new result places every specific M_k in the positive-dimension
set minus the finite-witness set. A global linear count of that difference
does not already imply this family-specific conclusion. Conversely, this
family has only logarithmically many members up to X and does not improve
the counting exponent or settle its sharp asymptotic.

2. ALL FINITE REPRESENTATIONS OF 289

I rebuilt the complete multiplication graph independently from
3*c' = c+289*a-b, using all580 input/output pairs for0<=c<=144.
Breadth-first reachability gives32 states and42 edges, exactly matching
the proposed certificate. Reverse reachability gives20 return states;
the remaining12 states form a closed set disjoint from0. Consequently
all finite0-to0 paths remain in the20-state return set, with no bound on
path length required.

I derived every polynomial potential independently from a shortest return
path: for a path from c to0 with tail polynomials Q_c,P_c, use
H_c=P_c-hQ_c, h=1-t^2-t^3+t^4+t^5. These independently derived coefficient
arrays match all supplied potentials. Every one of the26 edges inside
the return set satisfies the polynomial identity
 t H_c' = H_c + a h - b
coefficient by coefficient. The test did not merely evaluate at t=3.
The certificate thereby telescopes along every finite return and proves
P=hQ for all finite representations P(3)=289Q(3).

There is no lost case from constant terms zero: append high zero digits
to equalize word lengths; common low zero digits can also be removed
without changing the quotient or its local/universal type. Nonzero0/1
polynomials evaluate positively at3. Nonvacuity follows from the exact
product h*(1+t^2+t^3+t^5)=1+t^7+t^9+t^10, checked independently.

The graph representation is a known general technique. The proposed
contribution is the explicit global polynomial potential and resulting
classification at289, not invention of multiplication automata or a
claim about all integers.

3. CONSTRUCTIVE LOCAL FAMILY

For k>=2 the intervals defining Q_k have disjoint supports and degree
k^2-1. The listed supports of P_k are pairwise distinct: one group is
0 modulo k, another has residues1 through k-2, and the two final powers
are larger than all preceding ones. Thus P_k,Q_k are0/1 polynomials.

I independently rederived the identities for (t^(k+1)-1)Q_k and
(t^k-1)Q_k by shifting the block sums. Adding them gives
 P_k=(t^(k+1)+t^k-2)Q_k+R_k,
 R_k=3+2*(t+...+t^(k-1))-t^k.
Here R_k(3)=0, R_k is nonzero, and deg R_k=k<deg Q_k for every k>=2.
This proves the stated local representation of4*3^k-2. The k=1 case
must remain separate: Q_1=1 and P_1=1+t^2 give a universal representation.
The output length is exactly k(k+1)+1 for the displayed witnesses.
No minimality or assertion that all other witnesses are local follows.

Independent finite coefficient checks for k=2,...,34 passed. These are
supplementary to the all-k block-sum proof, not its justification.
